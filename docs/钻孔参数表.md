# 钻孔模块 —— 当前参数表（2026-10-17 现场验证版）

> 适用：`code/pc/` 钻孔模块 + `tests/manual_drill/drill_console.py` 现场控制台
> 所有参数可在控制台用 `CFG` 现场修改；本表为当前默认值。

## 一、通信与硬件

| 项目 | 值 | 备注 |
|---|---|---|
| Arduino 串口 | `COM7`（USB-SERIAL CH340） | 115200，固件 `FW motion-bootpos-p2-20260930` |
| 力传感器串口 | `COM6`（FTDI USB-RS485） | 19200，8-N-1（`config/force_sensor.json` 可改） |
| 传感器从站/寄存器 | 从站 `1`，寄存器 `0x9C40`（40000）× 2 | 32 位有符号、高字在前 |
| 传感器比例 | `scale = 1.0` | 未做砝码标定；检测用相对值 |
| 转盘 USB-CAN | `COM8` @ 921600 | 本模块不控制转盘（换头手动） |
| 传感器采样 | 约 10~13 Hz（单帧约 77 ms） | 受变送器响应时间限制 |

## 二、轴与坐标

| 项目 | 值 |
|---|---|
| 步长 | X/Y = 16.667 步/mm；Z = 100 步/mm；B = 1.111 步/度 |
| Z 方向 | **Z+ = 向下**；原点在最上（HOME 后 Z=0） |
| 自动抬升限制 | 不越过 Z=0（避免进入负坐标） |

## 三、钻孔参数（`DrillParams`）

| 参数 | 当前值 | 说明 |
|---|---|---|
| 进给速度 `feed_speed` | **500 步/秒（5 mm/s）** | 与手动 Z 速度一致；停钻过冲约 0.3~0.5 mm |
| 安全限深 `safe_depth_steps` | **2000 步（20 mm）** | 从每次 RUN 时的 Z 向下算 |
| 抬升距离 `lift_steps` | **2000 步（20 mm）** | 触发/中止后执行；目标不低于 Z=0 |
| 总超时 `timeout_seconds` | 60 s | 未触发则中止 |
| 常规速度 `normal_speed` | 500 步/秒 | 停止后恢复（SPEED 是全轴设置） |
| POS 轮询 | 100 ms | 只用于限深与显示，不参与阶跃判断 |
| 传感器过期 | 1.5 s | 超时判 `SENSOR_FAULT` |
| 传感器连续失败 | 10 次 | 超限判 `SENSOR_FAULT` |
| 抬升等待 | 20 s | 到位校验超时 |
| 停钻后停顿 `settle_seconds` | **0 s** | 不停留 |
| 检测后继续下钻 `extra_drill_seconds` | **0 s** | 不停留 |

## 四、阶跃检测参数（小信号模式）

| 参数 | 当前值 | 说明 |
|---|---|---|
| 基线 `baseline_seconds` | 1.0 s | 取静息 μ、σ |
| 噪声下限 `min_noise` | 0.5 | σ_eff = max(σ, 0.5) |
| 回落阈值倍数 `sigma_k` | 2.5 | 阈值 = max(2.5×σ_eff, min_drop) |
| 加载判定倍数 `load_k` | 1.5 | 峰值高出基线 ≥ 1.5×σ_eff 才算"已加载" |
| 最小回落 `min_drop` | 2.0 | 原始值单位；回落需 > 2 |
| 连续确认 `confirm_samples` | **1** | 首个满足样本立即触发 |
| 峰值回溯窗口 | 3.0 s | 过期峰值作废 |

> 触发时延：传感器采样 ≤77 ms + 处理；500 步/秒下约 0.3~0.5 mm 过冲（含 POS 轮询）。

## 五、停止与异常动作（统一路径）

```
STOP（固件先关钻头 PWM + 立即清目标停 Z）
→ DRILL STATUS 复核钻头 OFF
→ POS 记录 Z_stop / 钻深
→ SPEED 500 恢复（SPEED 为全轴设置）
→ 抬升 lift_steps（目标不低于 Z=0）
```

| 状态 | 触发条件 |
|---|---|
| `BREAKTHROUGH` | 力信号阶跃（当前判据） |
| `DEPTH_LIMIT` | 下钻达到 `safe_depth_steps` |
| `TIMEOUT` | 超过 `timeout_seconds` |
| `SENSOR_FAULT` | 无数据 / 连续失败 / 数据过期 |
| `LIMIT_STOP` | Zmax 限位或运动故障（PC 侧捕捉 `LIMIT_STOP`） |
| `Z_NEGATIVE` | 仅在"绝对 ZDOWN"调用路径（如 `motion_client` 的 `DC`）且 Z<0 时拒绝 |
| `DRILL_ON_FAILED` / `NO_ZDOWN` | 启动确认失败（仍会执行停止/抬升） |

> 现场控制台 `tests/manual_drill/drill_console.py` 内部把 `ZDOWN` 换成**相对下行**（`Z 100000`），
> 因此负坐标也能正常下钻；`motion_client` 的 `DC` 仍用固件 `ZDOWN`，负坐标会拒绝（保护），
> 直到固件烧录修复（源码已改为相对移动）。

## 七、已知问题与规避

| 问题 | 影响 | 当前规避 |
|---|---|---|
| 固件 `ZDOWN` 在 Z<0 时 32 位溢出反向 | Z 反而向上 | 控制台改用相对下行；固件源码已修复待烧录；`DC` 拒绝负 Z |
| 顶部 Z 限位未拦住向上（曾到 -2809） | 可能超出零点 | 自动抬升钳位 Z≥0；建议检查 D26 开关/接线 |
| 传感器比例未标定 | `value` 无物理单位 | 检测用 `raw` 相对值；需要时砝码标定并改 `scale` |
| 传感器曾长时间无变化 | 无阶跃可测 | 用 `scan_sensor.py` 做按压/寄存器扫描确认安装与接线 |

## 八、最常用命令

```powershell
python tests\manual_drill\drill_console.py        # 现场控制台（推荐）
python tests\manual_drill\drill_console.py --dry  # 不接传感器试跑
python tests\manual_drill\scan_sensor.py          # 传感器寄存器/按压诊断
python -m unittest discover -s tests -v           # 离线测试
```

控制台：`POS` 看坐标；`RUN` 开始钻孔；`CFG` 改参数；`S/F/M` 看力值；`ZERO` 坐标清零（不动机械）；`Q` 退出（自动发 E）。
