# 钻孔 D1-D3 指令（简单版）

> 工具：T1 = 电极头，T2 = 钻孔头。  
> 当前：**钻头不转**，D1 只下 Z；D3 是电极移动。  
> 启动：双击 `run_drill_test.bat`

## 只做这几步

```text
1.  POS（这里是显示具体位置）
2.  电极头朝下 → TZ（这里不用管 只需要知道初始位置就行了）
3.  TE
4.  SAFE 0（这一步就是定safe Z的位置 你是不需要定的）
5.  DRILLSTART 2250（这一步就是顶下开始开启钻头的Z 然后给定一个初始高度干系）
6.  D1（D1的操作：电极头换钻头 开钻 回到SAFE_Z）
7.  D2(换电极头)
8.  OFFSET 0（这个参数源自于Z目前最后一步的算法 目前是直接·）
9.  INSERT 0（目前我的改动只基于Insert 你也只要改动insert 就好）
10. D3（就是第三步 电极头开始放（你们可以基于后面的内容开始测））
11. Q（退出）
```

## 每步在做什么

| 步骤 | 作用 |
|---|---|
| `TZ` | 把电极头当前位置设为转盘工具1（这个我感觉你只要设计好就可以了） |
| `TE` | 转盘使能 |
| `SAFE 0` | 安全高度设为 0 |
| `DRILLSTART 2250` | 钻孔起点设为 2250 |
| `D1` | 走到起点、下 Z、记录 Z_STOP、抬回 SAFE；**不转钻头** |
| `D2` | 换到 T1 电极头 |
| `OFFSET 0` | 电极偏移先按 0 处理 |
| `INSERT 0` | 不额外下压 |
| `D3` | 电极按当前 Z_STOP + 0 移动，然后抬回 SAFE |
| `Q` | 退出并发送急停 |

## 只记 3 句话

```text
Z_STOP 每次 D1 自动更新，不用手动记。
当前不需要 RUN；RUN 会重新走 D1+D2+D3。
D1 不转钻头，只下 Z；D3 是电极最后一步。
```

## 出问题先停

```text
E（或者断电 我认为都可以 感谢）
```

然后检查 `POS`、`SAFE`、`DRILLSTART`，不要继续硬压。
