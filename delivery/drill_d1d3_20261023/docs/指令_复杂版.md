# 钻孔 D1-D3 说明（复杂版）

> 默认前提：**所有 Z 参数已经测好并保存在标定文件里**。  
> 本文不重复给具体 Z 数值；操作时直接使用已保存的参数。  
> 当前配置：钻头不转（`drill_duty=0`），D1 只下 Z；D3 为电极移动。

---

## 1. 工具与端口

```text
T1 = 电极头
T2 = 钻孔头
T3 = 第三工具/未用

Arduino：COM7，115200
转盘：COM8，921600
力传感器：COM6，19200
固件：FW motion-bootpos-p2-20260930
```

## 2. 标准流程

前提：设备已上电，标定文件已存在，Z 参数不需要重新输入。

```text
1. 双击 run_drill_test.bat
2. 电极头朝下 → TZ
3. TE
4. D1
5. D2
6. D3
7. Q
```

说明：

- `TZ` 只设转盘零点，和 Z 轴坐标无关；
- `TE` 转盘使能；
- `D1` 使用已保存的钻孔起点和安全高度，结束后自动更新 `Z_STOP`；
- `D2` 换到电极头；
- `D3` 使用当前 `Z_STOP`、已保存的 `offset` 和 `insert`；
- `Q` 退出并发送急停。

**不需要在本文档里手动输入 SAFE、DRILLSTART、OFFSET 的具体 Z 值。**

## 3. D1 / D2 / D3 的职责

```text
D1：抬到安全高度 → 转 T2 → 到钻孔起点 → 下 Z/传感器流程
    → 记录 Z_STOP → 抬回安全高度

D2：抬到安全高度 → 转 T1 电极头（只换头）

D3：抬到安全高度 → 确认 T1
    → 目标 = Z_STOP + offset + insert
    → 移动电极 → 抬回安全高度
```

当前：

- D1 不转钻头，只下 Z；
- `Z_STOP` 每次 D1 自动更新，不需要手动保存；
- `offset` 和 `insert` 使用已测好的标定值；
- `RUN` 会重新执行 D1+D2+D3，不是必须。

## 4. 什么时候才需要重新标定

只有以下情况才需要重新测 Z：

- 换了钻头或电极；
- 换了夹具或样品高度；
- 重新上电后 Z 零点变了；
- D3 明显压得太深或够不到。

需要时使用：

```text
SAFE
DRILLSTART
DRILLSTART s
ECAL
OFFSET
INSERT
```

具体 Z 值按现场测量，不在本说明中写死。

## 6. Z_STOP 与 offset

```text
Z_STOP   = D1 当前这次结束时记录的绝对 Z
offset   = 已测好的电极偏移
insert   = 已设置的额外下压
D3 目标  = Z_STOP + offset + insert
```

- `Z_STOP` 每次 D1 自动更新，不用手动维护；
- 重启控制台后如果还想复用上一次结果，才需要 `ZSTOP`；
- 当前不需要在文档中给出 Z_STOP 数值。

## 8. 常见问题

| 现象 | 检查 |
|---|---|
| Arduino 打不开 | COM7 是否被占用；拔插 USB；重启控制台 |
| 转盘保持故障 / Write timeout | USB-CAN 供电/线/干扰；断 24V 后重插 USB |
| 传感器无变化 | COM6、接线、`S` 按压测试；确认受力路径 |
| D3 目标不对 | 当前 `Z_STOP`、`offset`、`insert` 是否一致 |
| D1 不下 Z | 起点是否有效；是否在限位；控制台是否报错 |
| USB 掉线 | 转盘和 Arduino 分开 USB 口；用带供电 Hub |

## 9. 安全

1. `E` 随时可用，手边能断电。
2. 换头前必须在安全高度。
3. 当前 D1 不转钻头，往下压到材料会堵转；不要当正常钻削用。
4. 先代用材料，再上活体。
5. 顶部限位、Z 负坐标、USB 掉线问题先确认。
