# 数据与 JSON 记录说明

## 1. 这些 JSON 是什么

| 文件 | 性质 | 是否保留历史 |
|---|---|---|
| `force_sensor.json` | 传感器配置（COM/波特率/寄存器/scale） | 否，配置 |
| `safe_z.json` | 最后一次 SAFE 值 | 否，每次保存会覆盖 |
| `drill_start_z.json` | 最后一次 DRILL_START 值 | 否，每次保存会覆盖 |
| `electrode_calibration.json` | 最后一次电极 offset/insert | 否，每次 ECAL/OFFSET 会覆盖 |
| `xy_pixel_calibration.json` | 视觉像素标定配置 | 否，配置 |
| `vision_position.json` | 视觉位置配置 | 否，配置 |

**结论：这些 JSON 保存的是“当前最新值/配置”，不是完整历史。**

## 2. 自动记录的数据

每次运行会自动写入 `motion_logs\`：

```text
YYYYMMDD_HHMMSS.log          串口 TX/RX、[DC] 开始/汇总/结束
sensor_YYYYMMDD_HHMMSS.csv   传感器原始采样
drill_event_YYYYMMDD_HHMMSS.csv 触发前后窗口
```

这些是追加记录，不覆盖旧日志。

## 3. 以后每次实验建议追加一条记录

文件：

```text
data\run_records.csv
```

建议每次 D1/D3 后追加一行，字段见表头：

```text
date, operator, run_id,
tool_electrode, tool_drill, drill_duty,
feed_speed, safe_depth_steps, lift_steps,
z_start, z_stop, depth_steps, status,
sensor_min, sensor_max,
offset_steps, insert_steps,
log_file, video_file, notes
```

- `log_file` 填对应的 `motion_logs\*.log`；
- `video_file` 填对应视频；
- `status` 填 `BREAKTHROUGH / DEPTH_LIMIT / NO_ZDOWN / ...`；
- 每次只追加，不覆盖历史。

## 4. 标定值覆盖前先备份

如果重新 `SAFE`、`DRILLSTART`、`ECAL`，旧 JSON 会被覆盖。  
建议先复制到：

```text
config\calibration_YYYYMMDD\
```

本包已保留 `config\calibration_20261023\`。

## 5. 一句话

```text
JSON = 最新配置/标定值，不是历史。
历史数据 = motion_logs\ 自动日志 + data\run_records.csv 人工追加。
```
